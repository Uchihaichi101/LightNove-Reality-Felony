REALITY: FELONY — Website v2

Mở index.html bằng trình duyệt.

Điểm mới:
- Có nút "✎ Quản lý".
- Tự thêm Act.
- Tự viết chương và chọn Act.
- Tự thêm/sửa/xóa nhân vật.
- Tự thêm/sửa/xóa thuật ngữ/lore.
- Tự thêm/sửa/xóa mốc Timeline.
- Dữ liệu tự lưu trong trình duyệt bằng localStorage.
- Xuất toàn bộ dữ liệu thành reality-felony-backup.json để sao lưu.
- Nhập lại file JSON để khôi phục.

Lưu ý:
- Đây là bản chạy cục bộ. Nếu xóa dữ liệu trình duyệt, dữ liệu localStorage có thể mất, nên hãy xuất JSON sao lưu định kỳ.
- Bản mẫu có thể thay bằng dữ liệu thật của bạn.
